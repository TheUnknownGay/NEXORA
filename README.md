# NEXORA — Plateforme Web Multimédia Open Source

NEXORA est une plateforme web moderne conçue pour la découverte et la gestion de contenus multimédias (films, séries, animés).

## Fonctionnalités

- **Interface Premium** : Design sombre immersif et responsive.
- **Catalogue Intelligent** : Filtrez par genre et recherchez vos contenus préférés.
- **NEXORA Mood** : Trouvez quoi regarder selon votre humeur.
- **NEXORA Roulette** : Laissez le hasard choisir pour vous.
- **Bibliothèque Personnelle** : Stockage local de vos favoris et historique (sans compte).
- **PWA** : Installable sur mobile et ordinateur pour une expérience fluide.

## Stack Technique

- **React / TypeScript / Vite**
- **Tailwind CSS** (Design)
- **Framer Motion** (Animations)
- **Lucide React** (Icônes)
- **React Router (HashRouter)** (Navigation GitHub Pages)

## Déploiement

Le projet est configuré pour un déploiement automatique sur **GitHub Pages** via GitHub Actions.

## Installation Locale

```bash
npm install
npm run dev
```
